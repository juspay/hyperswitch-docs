# D24

D24 routes card payments through a hosted redirect. It supports payments in Chile only, in CLP and USD. The redirect completes with automatic capture and supports refunds. Mandates are not available for this payment route.

### Authentication

Provide the **API Key**, **Read-only API Key**, and **API Signature** requested by the connector configuration. These labels map to the three accepted signature-key fields in [`D24AuthType::try_from()`](https://github.com/juspay/hyperswitch/blob/d03f8547d6367fab56690e4f5043590be4935dcd/crates/hyperswitch_connectors/src/connectors/d24/transformers.rs#L74-L94) and are declared in the [`d24.connector_auth.SignatureKey` configuration](https://github.com/juspay/hyperswitch/blob/d03f8547d6367fab56690e4f5043590be4935dcd/crates/connector_configs/toml/sandbox.toml#L9155-L9158).

### Before you start

D24 is not offered in the Hyperswitch control center. Contact the Hyperswitch team to enable it for your account. The dashboard boundary comes from [`connectorList`](https://github.com/juspay/hyperswitch-control-center/blob/19be3838fdb46a2fad8b1fe5f9090533ebd45119/src/screens/Connectors/ConnectorUtils.res#L89-L205).

### Webhooks

D24 webhooks are not currently supported. The object lookup, event lookup, and resource lookup methods all return `WebhooksNotImplemented`; use payment sync for payment status because its request builder is implemented. See [`IncomingWebhook for D24`](https://github.com/juspay/hyperswitch/blob/d03f8547d6367fab56690e4f5043590be4935dcd/crates/hyperswitch_connectors/src/connectors/d24.rs#L348-L371) and [`ConnectorIntegration<PSync>`](https://github.com/juspay/hyperswitch/blob/d03f8547d6367fab56690e4f5043590be4935dcd/crates/hyperswitch_connectors/src/connectors/d24.rs#L269-L318).

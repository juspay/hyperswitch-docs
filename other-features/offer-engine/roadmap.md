# Roadmap

#### Offer configuration UI

Today, offers are created and managed together with the Hyperswitch team (what's configurable). A self-serve **offer management UI in the Hyperswitch Control Center** is planned, letting you:

* Create offers directly — code, title, description, discount, validity period
* Upload and manage BIN lists
* Set budgets (count / amount) and per-card velocity rules
* Pause, resume, update, and end offers yourself
* Track redemptions and remaining budget per offer

#### Merchant onboarding & automatic merchant creation

Today, your Offer Engine merchant account, API key, and credentials are provisioned manually by the Hyperswitch team during onboarding. Planned improvements:

* **Guided merchant onboarding** for Offers from within the Hyperswitch dashboard
* **Automatic Offer Engine merchant creation** when the feature is enabled — no manual account setup, credentials provisioned and stored behind the scenes
